# Branch Colors for App Themes

**Value type:** `published screen value` = the official source itself publishes the hex/RGB. `conversion from official print color (labeled)` = the official source gives only a Pantone (PMS) value and a named conversion source supplies the screen value. Rows with a PMS value and no screen value are marked `print only`. `provided by Grok, not yet found on an official page` = value supplied by Grok and added by the user's decision; not yet confirmed on an official page.

## Guidance for assistants

- Colors only. Never use logos, seals, emblems, or insignia.
- Prefer `published screen value` rows. You may use rows typed `conversion from official print color (labeled)` or `provided by Grok, not yet found on an official page` (status `usable (labeled)`) and keep their label. If a branch has none of these, use a plain theme. Never invent a hex from a PMS value.
- Use **sourced** or **usable (labeled)** rows only; never UNVERIFIED rows.
- Text must meet WCAG AA contrast (4.5:1 for body text). Use branch colors for accents and headers; adjust the shade or fall back to dark or light neutral text when a branch color fails contrast.
- Always offer the user a plain theme.
